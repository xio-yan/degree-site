# DegreePath｜實踐大學高雄校區 112 級畢業進度檢核

網站：<https://xio-yan.github.io/degree-site/>

此網站供個人規劃使用，並非學校的正式畢業審查系統。

## 功能

- 五個頁面：畢業總覽、修課紀錄、學程分析、畢業條件、資料管理。
- 40 門系選修可依名稱、代碼、年級及學程篩選。
- 四學程每個至少 12 學分，須至少完成兩個；同一門課不可重複認列。
- 學程運算採最小費用最大流，尋找最多可同時完成的學程並列出實際課程分配。
- 校訂必修 18、院訂必修 8、系訂必修 51、興趣自選 10、選修 41、總學分 128。
- 英文新舊共 10 門不同課程擇 4 門（8 學分），由學生勾選修習及格狀態。
- 興趣自選至少五門、四個領域及十學分；可自行新增自由選修。
- localStorage 儲存、JSON 備份匯出／匯入、舊版瀏覽器紀錄遷移。
- 手機底部導覽和桌機側邊欄，不依賴外部 CDN。

## 結構

| 檔案 | 用途 |
| --- | --- |
| index.html | HTML 入口與導覽 |
| style.css | 響應式介面 |

## 為什麼沒有伺服器後端？

GitHub Pages 無法執行 Node.js 或 Python 伺服器。本站在用戶端使用獨立計算引擎，不需要登入、學籍資料庫或使用者資料上傳，且不會跨裝置同步。後續若要增加帳號或雲端同步，才需要安全的後端及身分驗證。

## 學程算法

在 112 級四學程資料裡，「物件導向程式設計」為唯一可認列的 2 學分系選修，三門 3 學分課加這門 2 學分仍只有 11，因此每個達成 12 學分的完整學程，都至少需要四門不同的 3 學分課。學程計算對四學程所有子集合建立容量限制，運用最小費用最大流確認實際分配；偏好把可認列學程較少的課優先分配，保留共用課彈性。

未用於最佳學程分配的已修系選修，仍計入系選修總學分。

## 舊資料遷移

首次打開新版時，若沒有新版資料，會自動讀取舊的兩組瀏覽器儲存鍵：usc112-checked-v1 和 usc112-extra-v2。新備份格式版本是 3，同時仍支援上一版含 checked 和 extra 欄位的 JSON 備份。

## 審核與來源

## 部署與驗收

GitHub Pages 使用 main 分支根目錄，更新後會自動部署。

建議測試：首頁載入四學程與畢業條件；切換勾選時即時更新；同課不重複認列；英文不同四門達到八學分；新增自填課程後重新整理不遺失；匯出並重新匯入備份。

請不要把個人修課紀錄 JSON 上傳到公開的 GitHub 儲存庫。
